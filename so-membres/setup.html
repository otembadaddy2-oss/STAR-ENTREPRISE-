Configuration du compte — STAR ENTREPRISE

Page à usage unique : crée le premier compte administrateur du groupe (ou un compte supplémentaire pour une filiale). Le jeton de configuration t'a été communiqué séparément — ne le partage avec personne.

Une fois ton compte créé, ouvre l'application S.O et connecte-toi avec cet identifiant et ce mot de passe. Tu peux revenir sur cette page plus tard pour ajouter d'autres comptes (une personne par filiale, par exemple), toujours avec le même jeton de configuration.
