    Comment obtenir ces deux informations ?
    1. Sur developers.facebook.com : créer une application « Entreprise » et ajouter le produit WhatsApp.
    2. Dans WhatsApp → Configuration de l'API : ajouter le numéro +242 05 597 24 27 et le confirmer par le code reçu (SMS ou appel). Le numéro ne doit pas être utilisé dans l'application WhatsApp normale.
    3. Copier l'identifiant du numéro de téléphone (phone_number_id) dans la case ci-dessus.
    4. Dans Paramètres de l'entreprise → Utilisateurs système : créer un utilisateur système, lui donner l'application et créer un jeton permanent avec les droits whatsapp_business_messaging et whatsapp_business_management. Le coller ci-dessus.
    5. Dans WhatsApp → Configuration → Webhook : coller l'adresse ci-dessus, saisir le mot de vérification (variable Netlify WHATSAPP_VERIFY_TOKEN) et s'abonner au champ messages.
    6. Revenir ici, appuyer sur Tester la connexion, puis écrire un message au numéro depuis un autre téléphone.
