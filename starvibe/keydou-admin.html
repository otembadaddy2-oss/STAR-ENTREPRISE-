Une ligne = un appareil où KOMYO est installée. Le nom et le numéro apparaissent dès que la personne se connecte à KOMYO ou écrit ses coordonnées à Keydou ; « Pas encore identifié » = installée, mais personne n'est encore connecté dessus.

Comment ça marche
  1. Un membre qui a oublié son PIN fait une demande depuis KOMYO (numéro + nom).
  2. Vérifie que c'est bien lui : compare le nom indiqué avec le profil KOMYO et la ville, ou appelle-le.
  3. Touche « Générer le code » : un code à 6 chiffres s'affiche une seule fois. Envoie-le-lui par WhatsApp (le bouton prépare le message).
  4. Il saisit le code et choisit son nouveau PIN (4 ou 5 chiffres). Le code vaut 24 h, 5 essais.

1. Recevoir « Valider le dépôt ? Oui / Non » sur ce téléphone

Quand un client touche « J'ai payé », une notification apparaît sur ton téléphone avec deux boutons. Tu regardes ton MTN Money, tu touches « Reçu, valider » : Keydou répond tout de suite au client. Ouvre cette page sur le téléphone qui reçoit les dépôts (+242 06 656 50 50).

iPhone : d'abord « Partager » puis « Sur l'écran d'accueil », ouvre l'icône, puis active. Sur iPhone les boutons Oui/Non s'ouvrent dans une page au lieu de s'afficher dans la notification.

2. Reconnaissance automatique des dépôts (SMS)

Une application Android de transfert de SMS (par exemple « SmsForwarder », « MacroDroid » ou « Tasker ») envoie à Keydou chaque SMS de dépôt reçu d'MTN/Airtel. Si le montant est exact et que le numéro de l'expéditeur est celui du client, le dépôt est validé tout seul. Sinon tu reçois la notification Oui/Non.

  1. Installe l'application de transfert de SMS sur le téléphone qui reçoit les dépôts.
  2. Règle : « si le SMS vient d'MTN / MobileMoney (et Airtel Money) » → « envoyer vers le webhook ci-dessus ».
  3. Corps de la requête : {"message":"[corps du SMS]","from":"[expéditeur]"} (le mot entre crochets est la variable de l'application).
  4. Filtre l'expéditeur : seuls les SMS d'MTN / Airtel doivent partir.
