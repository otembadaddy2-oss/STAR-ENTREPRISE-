# X SAPHIR ARENA — projection du jeu d'aventure réaliste (version de travail du 19/11/2026)

Demande de Carry : voir la création « de A à Z », ce qui se fait sur Higgsfield, et avoir une idée de ce qui vient.
Légende : **[canon]** = déjà dans les documents du projet ; **[proposition]** = à valider par Carry ; **[à mesurer]** = pas encore vérifié.
Aucun chiffre de durée ni de coût n'est promis : les crédits Higgsfield se vérifient avec l'outil d'estimation avant chaque envoi.

## 1. Ce que sera le jeu (en une page)
- **Combat réaliste** (1 contre 1, style Street Fighter, personnages originaux X SAPHIR) : coups légers/moyens/forts, combos, spéciaux, super, ralenti à l'impact, tremblement d'écran, « rage de démon » des boss sous 30 % de vie.
- **Mode Aventure** [proposition] : chapitres reliés par des scènes dessinées (affiches Higgsfield + dialogues), chaque chapitre se termine par un combat ; progression sauvegardée sur le téléphone.
- **Boss** : Mordrek (intermédiaire), Kor-Mal, puis Satana Nakata (boss final).
- **Steel Pursuit** : jeu de course/poursuite séparé avec les 4 héroïnes (Nyra Volt, Vipera Shade, Luna Blaze + la 4e à nommer).
- **Téléphone et PC**, installable, réglage « Économie » (pas de surchauffe), caché du public jusqu'au « publie » de Carry.

## 2. Qui fait quoi

Solde Higgsfield connu : environ 5,4 crédits [estimation, à re-vérifier avec l'outil avant de dépenser]. Pour 11 personnages complets il faudra donc recharger.

## 3. Étapes, chacune avec un résultat que Carry peut tester sur son téléphone
1. **Validation** (Carry) : liste des combattants, pouvoirs, nom de la 4e héroïne.
2. **Premier duel jouable : Calpros contre Satana Nakata**, une arène. On voit si le niveau visuel est bon avant de produire le reste. Besoin : « oui poses » + crédits.
3. **4 combattants** (+ Nia Mensah, Ayanda Zulu), 3 arènes.
4. **8 combattants + 3 boss**, rage de démon, super, transformations.
5. **Mode Aventure** : chapitres, dialogues, scènes, sauvegarde.
6. **Steel Pursuit**.
7. **Réglages finaux, tests complets sur téléphone**, puis **un seul déploiement** sur « publie ».

## 4. Risques honnêtes
- Des images fixes animées par le code ne valent pas des modèles 3D animés. Elles peuvent être très belles et fluides, mais pas au niveau d'un jeu de studio. Pour un rendu « film », il faudrait des vidéos par plan (cher) ou un vrai travail 3D.
- Garder le **même visage et la même armure** d'une pose à l'autre est le point le plus difficile avec la génération d'images : on le teste d'abord sur Calpros, avec ses affiches comme références.
- La vitesse sur un vrai téléphone ne se mesure pas dans mon environnement : seul le téléphone de Carry le dira.
- Droits : personnages et univers sont originaux ; aucun personnage de Street Fighter n'est repris.
