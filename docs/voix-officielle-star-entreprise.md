## Comment générer une nouvelle prise avec cette voix

1. Ouvrir ElevenLabs → **Text to Speech**.
2. Choisir la voix **Clémence** (ou coller l'ID `LFo5X4P9PhYaOLBA9Hyh` dans la recherche de voix).
3. Coller le texte du nouveau spot et générer.
4. Écouter côte à côte avec le fichier de référence ci-dessus avant de valider.
5. Télécharger le MP3 et le ranger dans le dossier du spot concerné, sous `assets/video/<nom-du-spot>/`.
